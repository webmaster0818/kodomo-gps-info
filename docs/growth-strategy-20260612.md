# gps-kodomo.com 成長戦略（最短×最大・ASP以外）

作成日: 2026-06-12 / 根拠: GSC実データ（直近28日: 24クリック / 625表示 / 平均掲載順位13.5位）

## 現状診断（GSC実データ）

- 83ページ。月次推移: 4月 101imp → 5月 553imp → 6月(11日まで) 241imp と成長中
- **3サイト（gamekaitori/artmake/kodomo-gps）中、平均順位が最も良い（13.5位）**。CTRも3.8%と健全。ドメイン評価の立ち上がりが速い
- **勝ちクラスタは「学校×GPS」**: knowledge/school-rules（95imp・7.6位・6クリック）、school-trip（6.6位・7クリック）、「小学校 gps 許可」6.2位 → 親の「学校に持たせていい？」という不安系クエリで Google に認められている
- **最大の単一ページ機会: review/anshin-watcher（81imp・15.5位）**。サブクエリ「寿命」(21imp・10位)「2台目」「何人まで」(8位)「家族招待」(6位)が既に表示中 → 1ページ増強で大きく刈れる
- Top5圏内が既に複数: purpose/elementary 2.3位、sayuu-vs-mitene 3.0位、bot-vs-mitene 5.4位、summer-winter 5.8位、privacy 6.0位
- mixiみてね機種別クエリ（mg05、トークPlus）が7位前後 → 機種別レビューの需要を確認

## 重要な前提: 季節性
子供GPSの最需要期は**2〜4月（新入学準備）**。次点で8月末〜9月（新学期）と夏休み前。
**今(6月)から評価を貯め、来年2月の入学商戦でドメインピークを迎える逆算設計が全体方針。**

## 戦略の柱（優先順）

### 柱1: あんしんウォッチャー特化増強【最短・今週】
81impで15.5位は放置損。GSCに出ているサブクエリを全て見出し化:
- 「2台目の月額」「何人まで見守れるか」「家族招待のやり方」「バッテリー寿命・交換」
- 上位5位の競合調査をしてから構成決定（社内ルール準拠）
- 同型で halococo（10.6位）、soranome、botトークも順次増強

### 柱2: 「学校×GPS」クラスタの完全制覇【勝ち筋の拡張】
既に7位前後で戦えている領域を面で取る:
- 「学校許可の取り方+申請理由の書き方テンプレ」（「gps 申請理由」13位で表示済み）
- 「ランドセルへの付け方」「学校で禁止されたときの対処」「先生への伝え方」
- **一次データ: 主要自治体・教育委員会のGPS持ち込みルール/見守り端末配布・補助制度の調査DB**（公式サイト出典付き・無料で調査可能）← AIが書けない固有情報でInformation Gain最大化

### 柱3: 機種別レビュー展開【表示済み需要の刈り取り】
- mixiみてねGPS第5世代(MG-05)、トークPlus など**機種・世代別ページ**を追加（「mg05 reviews」7位で表示済み）
- 各機種の料金プラン・スペックを定点調査し「料金改定履歴」を付ける（一次データ化）

### 柱4: striking distance リライト【柱1と並行】
- battery(13.5位)、history-check(14.7位)、when-to-start(16.5位)、compare/accuracy(25.9位・20imp)をリライト
- Top5固定化: school-rules(7.6)、size-weight(7.1)、privacy(6.0)はtitle/CTR改善で3位以内へ
- 「gps 子供 安い」(20.4位・7imp)→ compare/price(26.8位)を「月額最安ランキング」へ強化

### 柱5: 実機テスト【最強のE-E-A-T・費用要相談】
- 主要3機種程度を実際に購入し、精度・電池持ち・通知速度を同条件比較（小学生の通学路で実測）
- 端末代+月額の費用が発生するため**実施判断はご相談**（1台3,000〜5,000円+月額500円程度）
- 実施できれば「実測データ」は競合上位（ほぼ全て公式情報の転載）への最大の差別化

### 柱6: 夏休み前需要の先回り【6月中＝今】
- 「夏休み 子供 見守り」「学童 GPS」「帰省 子供 GPS」など7月需要のコンテンツを6月中に公開（インデックス・評価のリードタイム確保）
- summer-winter(5.8位)があるので拡張で対応可能

### 柱7: 非検索流入（ASP以外）
- **Instagram/X で「学校のGPSルール調査」「料金比較表」を画像投稿** — 小学生ママ層はInstagram親和性が高い。柱2の自治体調査データの転用で工数最小
- 入学準備系のハッシュタグ（#入学準備 #小1の壁）が春に爆発する → 春までにアカウントを育成
